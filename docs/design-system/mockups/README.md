# Approved mockups

Static pictures of the look the team lead approved on 2026-11-26. They are reference
material for building the design system, not application code.

| File         | Shows                                                                                  |
| ------------ | -------------------------------------------------------------------------------------- |
| `elder.html` | Elderly side: login, home, courses, mode choice, play, results, booking, high contrast |
| `admin.html` | Admin console: courses, Pattern Editor, analytics, users with a confirm dialog         |

Open a file directly in a browser. The font is loaded from `src/app/fonts/`, so open the
files from inside the repository.

The rules live in `docs/superpowers/specs/2026-11-26-design-system-design.md`. When a
mockup and that document disagree on a value, the document wins; where the document is
silent, the mockup wins. All names and numbers in the mockups are made up.
