Brain9 design system — หน้าจอจริงทั้งสองฝั่ง

ทุกหน้าใช้ค่าจากเอกสาร design system ตรงตามขนาดจริง: มือถือกว้าง 390px ตัวหนังสือ 20px · หน้าผู้ดูแลย่อเหลือ 80% (ตัวหนังสือ 16px) · ข้อมูลทั้งหมดเป็นข้อมูลสมมติ

ฝั่งผู้สูงอายุ (มือถือ)

เข้าสู่ระบบ → หน้าหลัก → คอร์ส → เลือกโหมด → เล่น → ผลถูก/ผิด → ผลลัพธ์ → จองคิว และหน้าหลักในโหมดตัดกันสูง

ฝั่งผู้ดูแล (คอมพิวเตอร์)

รายการคอร์ส · Pattern Editor · วิเคราะห์ผล · ผู้ใช้งานพร้อมหน้าต่างยืนยัน
