ฝั่งผู้ดูแล — ปรับใหม่ให้ดูมืออาชีพและใช้งานง่าย

โครงหน้าแบบ AdminLTE ที่ปรับให้ทันสมัย: เมนูซ้ายสีเข้ม แถบบน และกล่องเนื้อหา ใช้สีและฟอนต์ชุดเดียวกับฝั่งผู้สูงอายุ

  • โครงหน้าแบบ AdminLTEเมนูซ้ายสีเข้มแบ่งหมวดและพับได้ แถบบนมีค้นหา แจ้งเตือน และเมนูผู้ใช้
  • ปรับให้ทันสมัยไม่มีแถบสีหัวกล่อง ไม่มีไล่สี ใช้เส้นบาง มุม 8–10px และที่ว่างมากขึ้น
  • สถานะเป็นจุดสี + คำแทนป้ายสีก้อนใหญ่ อ่านเร็วและไม่รกตา
  • สีหลักใช้เท่าที่จำเป็นปุ่มหลัก เมนูที่เลือก ลิงก์ และเส้นกราฟ ที่เหลือเป็นสีกลาง
  • ตารางครบเครื่องค้นหา กรอง เรียงลำดับ เลือกหลายแถว ตัวเลขชิดขวา แบ่งหน้า
  • ตัวหนังสือ 14.5pxหัวข้อหน้า 22px เหมาะกับงานหน้าจอคอมพิวเตอร์ทั้งวัน
